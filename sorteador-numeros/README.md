<h1>Sorteador de Números 🎲</h1>
<p>Este projeto permite sortear números dentro em qualquer intervalo a ser definido pelo usuário.</p>

## Funcionalidades 🛠️
- 🎯 Define a quantidade de números a serem sorteados
- 🔢 Define o intervalo de números do sorteio
- 🧹 Reinicia o sorteador
- ⚠️ Impede erros por valores inválidos dentro da quantidade e intervalo de números 

## Recusos em JavaScript ⚙️
Nesse projeto foram utilizados recursos como:
- Variáveis
- Funções
- Arrays
- Condicionais (`if` / `else`)
- Laços de repetição (`for` / `while`)
- Geração de números aleatórios (`Math.random`)
- Manipulação do HTML com Documento Object Model
