# 🎮 Aluguel de Jogos

Projeto desenvolvido nos cursos da Alura para praticar conceitos de **JavaScript**, simulando um sistema de aluguel e devolução de jogos.

## 📌 Sobre o projeto

O sistema permite alterar o status de um jogo entre **disponível para aluguel** e **alugado**.

Ao clicar no botão, a imagem e o texto do botão são atualizados de acordo com o status atual do jogo.

## 🚀 Funcionalidades

- Alugar jogos
- Devolver jogos
- Alterar visual do jogo alugado
- Alterar texto do botão
- Identificar o jogo selecionado
- Alternar o status do jogo

## 🎯 Objetivo

Praticar conceitos de JavaScript, principalmente **funções, parâmetros, manipulação do DOM e alteração dinâmica de classes e conteúdo HTML**.
