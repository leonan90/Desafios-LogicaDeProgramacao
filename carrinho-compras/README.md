# 🛒 Carrinho de Compras

Projeto desenvolvido nos cursos da Alura para praticar conceitos de **JavaScript**, simulando um carrinho de compras.

## 📌 Sobre o projeto

O sistema permite selecionar um produto, informar a quantidade e adicioná-lo ao carrinho.

O valor total da compra é calculado automaticamente conforme os produtos são adicionados.

## 🚀 Funcionalidades

- Seleção de produtos
- Definição da quantidade
- Validação dos dados
- Cálculo do valor dos produtos
- Cálculo do valor total da compra
- Exibição dos produtos no carrinho
- Limpeza do carrinho
- Atualização dinâmica da página

- `.value`
- `.textContent`
- `.innerHTML`
- `.split()`
- Template strings
- Operações matemáticas
- Manipulação do DOM
- Validação de dados

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Praticar conceitos básicos de JavaScript, principalmente **funções, validação de dados, manipulação do DOM e operações com valores**.
