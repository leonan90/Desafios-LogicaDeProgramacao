# 🎁 Amigo Secreto

Projeto desenvolvido nos cursos da Alura para praticar conceitos de **JavaScript**, simulando um sistema de sorteio de amigo secreto.

## 📌 Sobre o projeto

O sistema permite adicionar participantes, verificar nomes repetidos e realizar um sorteio entre os participantes.

O sorteio utiliza o algoritmo **Fisher-Yates** para embaralhar a lista e criar as combinações.

## 🚀 Funcionalidades

- Adicionar participantes
- Validar nomes vazios
- Impedir participantes duplicados
- Exibir a lista de participantes
- Exigir no mínimo 4 participantes
- Embaralhar participantes
- Realizar o sorteio
- Exibir os pares sorteados
- Desativar o botão após o sorteio
- Reiniciar o sorteio
